鼠标工具 1.5.1 · Windows 桌面版

使用方法
1. 解压到任意普通目录，双击 MouseControl.exe。
2. 在顶部选择鼠标，查看电量、DPI 与回报率。
3. 输入目标 DPI 或选择回报率，再点击对应的“应用”按钮。程序会读回确认。
4. “设备详情”和完整提示按页显示；设备较多时在选择面板翻页。
5. 需要持续观察时可开启“每 30 秒刷新”；编辑未应用的数值时暂缓自动刷新。

运行环境
Windows 10 / 11 x64，系统需安装 Microsoft Edge WebView2 Runtime。
多数系统已有该组件；缺失时从 Microsoft 官网安装 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/
程序无需管理员权限、雷云、Node.js 或 Python，不注册服务、自启动或账号。
界面使用 Naive UI 组件；默认客户区 900×480，最小 760×440 逻辑像素。
设备列表、详情及长消息按页查看，不使用滚动条。
界面和中文字体内嵌在 exe 中，不监听本地 HTTP 端口，不依赖在线字体。
运行时及其缓存不计入本程序体积。缓存位置：
%LOCALAPPDATA%\MouseControl\WebView2

支持范围
雷蛇已适配鼠标，以及开放 HID++ 接口的罗技鼠标、轨迹球。
按实际设备能力开放功能；普通 HID 或未实现的私有协议可能仅能识别。
罗技尚无本项目真机验证，不能理解为每个型号、每种连接方式均可设置。
未知电量不会伪装成 0%，只有等级或电压时显示实际取得的信息。
多只设备分别显示；设备断开不会自动将设置改发给另一只鼠标。
USB 与无线接收器同时连接时可能显示两个独立连接。

设置说明
不管理按键、宏、灯光、DPI 阶段或整套板载配置。
部分设备会保存当前 DPI；罗技板载模式下可能拒绝修改，请按界面提示操作。
写入失败不自动重试；提示“可能已改变”时请刷新核对。

错误反馈
1. 在程序错误弹窗或底部“诊断日志”中点击“复制诊断日志”。
2. 点击“提交 Issue”打开 GitHub 问题模板：
   https://github.com/Vex9th/mouse-control/issues/new?template=bug_report.yml
3. 填写鼠标型号、连接方式、程序与 Windows 版本、复现步骤和实际结果，
   将报告粘贴到“诊断日志”栏，检查后自行提交。
程序只打开模板页面，不会自动发送日志或创建 Issue。
报告会自动脱敏，发布前仍请检查内容；无需填写账号、序列号或完整设备路径。
若程序无法打开或无法复制报告，可在模板中说明情况。

本地错误日志仅使用一个文件：
%LOCALAPPDATA%\MouseControl\logs\error.log
最多保留 20 条记录且不超过 128 KiB；连续重复错误合并并累计次数。
日志保存失败时会提示，仍可复制当前内存中的诊断报告。

本版是桌面程序；未来网页方案需另做 WebHID 通信和逐设备验证。
第三方许可见 THIRD_PARTY_NOTICES.txt。

迈从：文档列出的新协议型号提供实验性电量、DPI 与回报率读取；没有迈从真机验证，设置暂不开放。
